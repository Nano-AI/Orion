How the pictures were made

Each picture is a node’s output texture, read back from the GPU after a real render. The mosaic was binned to half size first so every intermediate could be kept for read-back. Scene-linear stages are shown through a plain sRGB curve, without a gamut conversion, so early colors look flatter than they will on screen.

The look applied

  • Highlight recovery 0.5, denoise 1.5 / 1.0, sharpen 1.0
  • Dehaze 0.1, clarity 0.35, fusion 0.3
  • Exposure −0.3 EV, highlights −0.15, shadows +0.15
  • Cool shadows, warm highlights, vignette −0.8
  • Gradient mask from the top at −1 EV, refine 0.6
  • Grain 0.03, straighten 2°. Spot removal is off.

Timings and regenerating

Milliseconds are per shader at full resolution, profiled one command buffer per node. They show which shaders are expensive, not how long a frame takes. To rebuild everything here from the repository root:

./build/apps/bench/orion-bench <raw> \
  --stages docs/pipeline-graph/stages --demo
