What the benchmark says.

orion-bench on a real Sony A7R III raw, 7968 × 5320 (42.4 MP), Apple M4.

Where the GPU time goes.

205 nodes. Most stages are one node; pyramids make the rest. Click a segment, hover a node.

How it is timed

Normal renders put all dirty nodes in one command buffer. Profiling mode (Pipeline::setProfiling, used by orion-bench) gives each node its own, so each node's GPU time is separate.
