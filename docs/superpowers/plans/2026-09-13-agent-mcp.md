# Orion Agent Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An MCP client can cull and edit RAWs through Orion using proxies and JSON, with a human approving every sidecar write.

**Architecture:** One new command-line mode in the Swift app (`--agent`, five verbs, JSON out) reusing `Engine`, `Sidecar` and `Autosave`; a thin TypeScript MCP server that shells to it; a Python gate that drives the server end to end against a copy of a sample RAW.

**Tech Stack:** Swift 5.9 / SwiftUI app on CMake, Node 25 with native TS stripping, `@modelcontextprotocol/sdk`, `zod`, Python 3 stdlib.

**Spec:** `docs/superpowers/specs/2026-09-13-agent-mcp-design.md` — read it first; the verb and tool tables there are the contract.

## Global Constraints

- macOS 14 floor. No Rust. No GPL. No new engine (C++) dependencies.
- `app/AgentCLI.swift` under 300 lines. `mcp/server.ts` under 250 lines.
- Build and run any Orion binary with the sandbox off: `cmake --build build` (see the "Swift macro plugin server" note in the task).
- Commit with explicit paths only. Never `git add -A` or `git add .`. Another agent is editing the same tree.
- End every commit message with the two attribution lines given in the task prompt.
- Do not edit `planning/DECISIONS.md` or `planning/STATUS.md`; a later task owns them.

- [ ] **Step 4: Implement `AgentCLI.swift`.** Structure:

```swift
import AppKit
import Foundation

/// `Orion --agent <verb> …` — the agent surface. JSON on stdout, one line on
/// stderr and exit 2 (usage) or 1 (failure). See docs/superpowers/specs/2026-09-13-agent-mcp-design.md.
enum AgentCLI {
    enum Failure: Error { case usage(String), unknownKeys([String]), run(String) }
    enum Command: Equatable {
        case stats(raw: String)
        case proxy(raw: String, max: UInt32, out: String, state: String?)
        case apply(raw: String, edits: String, out: String, state: String?)
        case commit(raw: String, state: String)
        case flag(raw: String, rating: Int?, reject: Bool?)
    }
    static func parse(_ args: [String]) throws -> Command { /* find "--agent", read verb, walk "--k v" pairs */ }
    static func mergeEdits(base: Data, edits: Data) throws -> (state: Data, changed: [String]) {
        // JSONSerialization both to [String: Any]; allowed = Set(baseDict.keys);
        // unknown = edits.keys - allowed -> throw; overlay; JSONSerialization.data; JSONDecoder().decode(DevelopState.self) to prove it round-trips; return re-encoded via JSONEncoder (same encoder Autosave uses).
    }
    static func statsJSON(histogram: [UInt32], bins: Int) -> (clipLow: [Double], clipHigh: [Double], mean: [Double]) { /* per channel: total, first bin share, last bin share, weighted mean bin / Double(bins - 1) */ }

    @MainActor static func runCommandLine(_ args: [String]) -> Never {
        NSApplication.shared.setActivationPolicy(.accessory)
        do {
            let cmd = try parse(args)
            let out = try run(cmd)          // returns [String: Any]
            let data = try JSONSerialization.data(withJSONObject: out)
            FileHandle.standardOutput.write(data); FileHandle.standardOutput.write(Data("\n".utf8))
            exit(0)
        } catch Failure.usage(let m) { stderr("usage: \(m)"); exit(2) }
          catch Failure.unknownKeys(let k) { stderr("unknown keys \(k); allowed: …"); exit(2) }
          catch { stderr("orion: \(error)"); exit(1) }
    }
}
```

`run(_:)` per verb, per the spec table. For `stats` and `proxy`: `Engine()`, `open(path:)`, if `Sidecar.read(for:)?.develop` exists then `restore(encoded:)`; for `proxy` with `--state` restore that file's bytes after. Before calling `histogram`, check how `Engine+Render.swift` expects a render to have happened (read the function and its callers; if a render must be forced, do what `BatchExportDriver` does before export). `apply` with no `--state` and no sidecar uses `JSONEncoder().encode(engine.state)` after `open`. `commit` decodes the state file to `DevelopState` (fail on error) and calls `Autosave.toSidecar`. `flag` uses `Sidecar.merge(into:)` with the rating/reject rules from the spec.
