| **P2 — noise model depends on one CFA color** | `raw/NoiseProfile.cpp:65-73` samples only `x,y = 0,4,8,…`; all three horizontal taps are two pixels apart. On a 2×2 Bayer CFA, every sampled triplet has the color at `(0,0)`. The estimator then uses the **mean of all four** black levels (`:52-57`) and fits a single `a,b` (`:161-163`). `raw/RawImage.h:49-53` already exposes the actual CFA channel. Both develop (`pipe/DevelopCapture.cpp:319-320,690-708`) and HDR (`merge/HdrMerge.cpp:236-239,285-286`; `merge/Merge.cpp:185-187,220-223`) apply the resulting profile to RGB. `tests_tone.cpp:17-43` assigns identical noise and black levels to every synthetic channel, so it cannot detect the phase dependence. | **Definite phase selection; output severity unmeasured.** Changing which channel is top-left can change the estimated variance and therefore denoise/merge weights for the same per-channel noise. Add one deterministic synthetic Bayer check with different channel black/noise levels and a phase permutation; the fit should use all CFA phases or have an explicitly tested representative-channel policy. The smallest implementation is to sample all four phase offsets and normalize each by its actual `channelAt` black level before the existing bin/fit. It need not introduce a profile type. |
| **P2 — Stop can be lost before the HDR worker enters `run`** | `app/HdrMergePanel.swift:110-130` sets `mergeProgress = 0`, exposes Stop (`:70-75`), then schedules a detached worker. Stop calls the atomic `HdrMerge::cancel()` (`merge/HdrMerge.h:46-48`), but `HdrMerge::run` clears that atomic as its first statement (`merge/HdrMerge.cpp:208-210`). If Stop lands after scheduling and before the worker starts, the request is erased and the merge proceeds. This is separate from the already-reported long stage-boundary cancellation latency. | **Definite ordering window; frequency unmeasured.** A controllable pre-start worker gate should call Stop before letting `run` enter and assert no DNG is written. Establish the current run before enabling Stop, or keep the pending cancellation through entry; retain the reset only when a new run is explicitly begun without a pending Stop. |
