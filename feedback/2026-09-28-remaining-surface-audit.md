## Ranked findings

| **P1 — recorded session may not replay** | `InteractionLog.swift:97-100` writes `open \(path)` for every product open (`Engine+Document.swift:130`). `Scenario.swift:333-336` splits on spaces and `Scenario+Frame.swift:17-20` takes only `args.first`, so opening a normal path such as `/Users/Ada/Photo Shoot/1.ARW` produces a log that tries `/Users/Ada/Photo`. Separately, `Scenario+Frame.swift:22-46` documents that `open` is intentionally as-shot and `load` restores the sidecar, while the product's `Engine+Document.swift:130` emits the log's `open` before restore. Thus replay of a photo with prior saved edits starts in a different state. The current `minchecks 0` header means a replay can report success without asserting equivalence. | Use a scenario path grammar that accepts the complete path and record/replay the restored starting state, or use the existing `load` verb after making its path handling complete. A focused replay with a spaced path and a non-default sidecar is needed; none ran here. |
| **P2 — full-size watermark allocates a full-frame CPU mask** | `WatermarkRaster.swift:99-129` draws into a cropped RGBA tile and then allocates an 8-bit `width * height` frame mask, copying the tile into it. Every enabled GUI export (`OrionApp+Files.swift:513`) and every GUI batch photo (`BatchExportDriver.swift:137`) invokes this path; the export size estimate does too (`OrionApp.swift:360`). At 42 MP, the mask alone is ~42 MB decimal before the tile and writer's other buffers. An SVG with a large diagonal bounding box makes the temporary tile larger. This is source-derived allocation, **not measured RSS or a demonstrated OOM**. | If full-resolution RAM measurement shows pressure, pass the tile plus origin/stride to the writer or composite the tile at finalization, avoiding the full-frame mask. Measure enabled-watermark export peak against off first. Decision #284 explicitly chose a full-frame facade mask, so changing it requires revisiting that contract. |
| **P2 — watermark controls lack usable VoiceOver names/state** | `WatermarkPanel.swift:156-174` builds nine shape-only anchor buttons; `.help(a.title)` supplies a tooltip but no explicit accessible label or selected value. `:190-212` places a separate `Text` beside an unlabeled `Slider`, and the font `Picker` at `:125-134` has an empty hidden label.
