Opening it the first time

macOS stops the first launch because this alpha is signed ad hoc and isn't notarized. The app is the same either way; the warning is about who vouched for it.

  1. Drag Orion to Applications

    Open the downloaded disk image and drag Orion onto the Applications folder beside it.

  2. Open it from the right-click menu

    Right-click Orion in Applications, choose Open, then Open again. You do this once.

  3. No Open button? Use Terminal

    This clears the download flag macOS put on the app. It also lets Claude and other agents start Orion's MCP server.

    xattr -dr com.apple.quarantine /Applications/Orion.app

Supported cameras

Orion opens 21 raw file types. LibRaw decodes them.

  • Sony

    .arw .srf .sr2

    Tested on ARW

  • Fujifilm

    .raf

    Bayer sensors only. X-Trans files are refused

  • Adobe DNG

    .dng

    Mosaic and linear DNG. Drone and phone files untested

  • Canon, Nikon, Olympus, Panasonic, Leica, Pentax and more

    .cr2 .cr3 .crw .nef .nrw .orf .rw2 .rwl .raw .pef .srw .3fr .fff .iiq .erf .mrw

    Opened by LibRaw, not tested

Not supported: X-Trans sensors, sensors that are not red, green and blue, and JPEG, TIFF, PNG and HEIC input (planned). Tested on Sony ILCE-7M3 and ILCE-7RM3 files, plus a synthetic DNG; nothing else has been tried. LibRaw 0.22.2 lists 1,258 cameras: see LibRaw's supported cameras. Being on that list does not mean Orion has been tried on it.
