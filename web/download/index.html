Opening it the first time

No alpha build carries a developer signature: the Mac one is signed ad hoc and isn't notarized, the Windows one isn't signed at all. So both systems stop the first launch. The app is the same either way; the warning is about who vouched for it. Linux needs only chmod +x on the AppImage.

  1. macOS: drag Orion to Applications

    Open the downloaded disk image and drag Orion onto the Applications folder beside it.

  2. macOS: "can't be opened"? Right-click, Open

    Right-click Orion in Applications, choose Open, then Open again. You do this once.

  3. macOS: no Open button? Use Terminal

    This clears the download flag macOS put on the app. It also lets Claude and other agents start Orion's MCP server.

    xattr -dr com.apple.quarantine /Applications/Orion.app

  4. Windows: SmartScreen? More info, Run anyway

    SmartScreen says the publisher is unknown. Choose More info, then Run anyway. You do this once.
