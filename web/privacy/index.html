Privacy

Orion edits your photos on your computer. Your photos, raw files and edits are never uploaded. There is no account, no analytics, no crash reporting and no advertising.

What the app sends

Three things, and two of them only when you ask.

  • Update check

    To GitHub: a request for Orion's release list, then the update itself if there is a newer one. GitHub sees your IP address, as with any download.

    Five seconds after each launch, and when you choose Check for updates. There is no switch for it yet: block Orion in your firewall, or work offline, and Orion carries on without a word.

  • Feedback form

    To Tally (tally.so), in your browser: your system and its version, Orion's version and build, processor, graphics card, memory, screen size, minutes used and photos opened this session, and the open photo's camera model and file format. Never a file name, a folder or your user name.

    Only when you click Feedback, or Give feedback on the reminder. The facts ride in the link, so Tally receives them as the form opens; what you write is sent when you submit. Never show again stops the reminder.

  • Assistant and MCP server

    Orion's MCP server (orion-mcp) makes no network calls. The agent you run with it, Claude Code or Codex, sends what it reads to its own provider under that provider's terms: file names and folders, edit settings, photo statistics, capture data, and a JPEG preview of the photo up to 2048 pixels when it asks for one.

    Only when you open the assistant column or add orion-mcp to an agent yourself. Leave both alone and nothing goes.

What this site sends

No cookies, no analytics. Its fonts and images are served from the site itself.

  • Hosting

    GitHub Pages serves every page, so GitHub receives your IP address and browser details with each request, under GitHub's own privacy statement.

    Every visit.

  • Download page

    Your browser asks GitHub's API (api.github.com) for Orion's release list, to offer the newest file for your system.

    When the download page opens. Turn off scripts and the buttons open the release list on GitHub instead.

Not collected

Photos, raw files, previews, edits and sidecars stay on your disk, except what you let an agent read. So do your library, ratings and settings. Exports go where you save them, with location stripped by default.
